# TB67H450 基础驱动与编码器验证

日期：2026-10-23。基于 `develop` 的清理提交 `2b22c3711ad2709f9c6797e96ba228f0e3920f28`，以下为本轮未提交增量。目标是按新硬件接入左右轮原始编码器和开环驱动，不恢复旧 PID。

## 变更与依据

- 左 M4：PB6/PB7 使用 TIM16/17_CH1N；PC6/PC7 使用 TIM8 编码器。
- 右 M3：PB4/PB5 使用 TIM3_CH1/2；PD12/PD13 使用 TIM4 编码器。
- HAL 时基从 TIM17 迁至 TIM6，避免左轮 PWM 与 HAL 共用；TIM4 不再同时承担左 PWM 与右编码器。
- PWM 为 20 kHz，采用驱动/制动方式；CH1N 仅在主 CH1 关闭时按高有效输出使用。
- 启动只开启编码器计数。电机在显式限时请求后依次经过双低、双高唤醒、PWM；零、显式停车、期限到达或故障关闭输出。
- 10 ms 任务采样，16 位计数按模差分转换为增量，累计使用 64 位；未加入车体方向符号或每转计数换算。
- 对外请求暂限 ±300‰、10～2000 ms；单轮命令关闭另一轮。请求已接收与实际已输出分别报告。

硬件映射、数据手册引用、状态机和公开 API 见[基础接口](../基础电机与编码器接口.md)。
