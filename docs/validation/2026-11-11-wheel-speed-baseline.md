# 底盘速度环调试基线

2026-11-11 用户提供车轮直径 650 mm（0.650 m），并指出既有控制器审查资料中的电机参数。以下条件用于速度环设计与调试记录：

| 项目 | 数据和来源 |
| --- | --- |
| 电机 | JGA25-370，减速比 45，标称最高转速 280 RPM；见[控制器审查资料](../控制器审查与重构方案.md)第 1.2 节 |
| 编码器 | 用户提供 11 线；输出轴每圈 1980 counts，同一资料记载此前由用户确认 |
| 轮径 | 650 mm；用户 2026-11-11 提供 |
| 当前驱动 | 左轮 M2、右轮 M1；左编码器 TIM5、右编码器 TIM3，PWM 为 20 kHz |
| 采样与命令 | 当前每 10 ms 采样；开环命令限 ±800‰、最长 2000 ms，上电保持停车 |
| 夹爪 | PE11；PC1 打开 1750 μs，PC2 闭合 2250 μs |

按电机轴每圈 11 个 A/B 信号周期、45:1 减速比及定时器 TI12 四倍频计数换算，输出轴每圈为 11 × 45 × 4 = 1980 counts，与既有记录一致。按给定轮径及编码器计数换算，轮周长约 2.042 m，每 count 约 1.031 mm；10 ms 内 1 count 约为 3.03 RPM、0.103 m/s。280 RPM 对应的轮周线速度约 9.53 m/s，实际速度受供电、负载、打滑和驱动条件影响。

现有程序提供开环驱动及编码器原始增量，还没有速度控制器。旧控制器审查方案中 C/D 接口、TB6612 与 TIM12 等硬件描述对应历史版本；新速度环应以当前 TB67H450、M2/M1 与实际输出约束为基础。编码器计数假定与现用电机及编码器一致，调试中可由实际数据核对。PI 参数、可达速度和负载表现需根据调试数据整定；当前未烧录新速度环或开展闭环硬件测试。

曾按用户反馈增加 10 倍试验系数，现已按用户要求移除，恢复按 1980 counts/转计算。反馈、实际轮轴转速及编码器计数对应关系待独立实测。
