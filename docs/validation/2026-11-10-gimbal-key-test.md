# 云台舵机与按键测试

用户更正按键为 PC2、PC1，PE9 接普通位置舵机。按键另一端接 GND，内部上拉，按下为低电平。

首次有效按键以 1500 μs 为参考，PC2 增加 50 μs，PC1 减少 50 μs；每次按下动作一次，长按不连发，双键同时按下不调整。范围 1000～2000 μs，50 Hz；首次按键可能使舵机从原有位置移向该参考位置。复位后停止输出并重置参考值。

PE9 使用 GPIO 输出，由 TIM7 中断生成脉冲；右电机继续使用 TIM1。初始化时舵机信号保持低电平，收到有效按键才启动脉冲。定时器时钟按当前 240 MHz 配置为 1 MHz。普通位置舵机的可用脉宽和机械方向需实测确认。调试接线使用 UART8，电机上电保持停车。

Debug/Release 构建和按键模拟检查通过；首次动作、实际波形、PC2 电平与机械安全间隙待上板验证。CubeMX 重生成及中断抖动待验证。
