## 通过项

以下项目已在整车上执行并通过。本次验收以功能确认为准，未逐项记录量化数值；用户已确认不做量化精度补测，以功能验收结项并进入下一阶段（P3 视觉处理）。未量化项列于下方留作记录。

| 项目 | 内容 |
| --- | --- |
| IMU 静态 | `imu get heading` 输出 `valid=1`，帧周期满足 50 ms 失效门限；手转车体时左转/右转符号正确，跨 ±180° 连续无跳变 |
| 原地定角转向 | `chassis turn` 在 ±30°、±90°、±180° 双向均转到目标并停稳，`stop_reason=1`，无持续振荡 |

| 差速方向 | `chassis vw` 架空方向正确（左转为左轮后退、右轮前进），落地小半径转圈方向与陀螺一致；轮径/轮距的精确标定留到接近阶段 |
| 夹爪按键 | PC1 打开（1750 μs）、PC2 闭合（2300 μs）按键直达位置，PE11 输出正常 |
| 停车响应 | `motor stop`、`chassis stop` 与转向/直行到期均立即停止输入，车轮回到高阻 |

## 未量化项记录（不做补测）

验收结论为“功能通过”，以下项目本轮未留档量化数值；按 2026-11-21 决策，不再安排量化精度补测，直接进入视觉处理阶段：

- ±30°、±90°、±180° 各 10 次的外部测角最终误差（草案 ≤3°）与超调（草案 ≤5°）、调节时间和饱和比例。
- 直行 1000 mm 的卷尺实测距离与末端横向偏差，用于校正有效轮径；原地转圈校正有效轮距与差速比例。
- JY61P 实际帧率数值与漂移量，以及电机/夹爪动作时的干扰幅度。
- 夹爪开合机械耗时、保持需求与阻挡响应；当前记录的仍是脉宽，不是实测角度。
- 完整 CubeMX 重生成、故障关闭瞬态和 `rescue.ioc` 一致性核对，仍按原计划单独验证。
