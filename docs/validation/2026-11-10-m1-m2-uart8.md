# M1/M2 电机与 UART8 联调

用户确认左轮 M2、右轮 M1。固件使用以下资源：

| 功能 | 引脚 | 定时器 |
| --- | --- | --- |
| 左 M2 IN1 / IN2 | PA5 / PB3 | TIM2 CH1 / CH2，AF1 |
| 右 M1 IN1 / IN2 | PA8 / PA11 | TIM1 CH1 / CH4，AF1 |
| 左编码器 | PA0 / PA1 | TIM5 CH1 / CH2，AF2 |
| 右编码器 | PA6 / PA7 | TIM3 CH1 / CH2，AF2 |
| 调试串口 | PE1 TX / PE0 RX | UART8，AF8，115200 8N1 |

CN5 第 2 脚为 TX，第 3 脚为 RX，第 4 脚为 GND；第 1 脚为 VCC。VOFA 选择 FireWater，100 ms 周期依次显示左右占空比、左右 10 ms 编码器增量、故障标志。命令结尾加换行，`motor stop` 停车；`motor both 100 100 2000` 表示双轮 10% 持续 2 秒。

上电或复位后双轮 10% 运行 60 秒，停车或新命令可提前覆盖。正常停车先将同一计时器的两路比较值同时提交为零，再切换为 GPIO 低电平；不可恢复故障入口仍有逐脚切换的瞬态风险。方向、实际电压和驱动波形待实测。CubeMX 完整重生成尚未验证。

Debug 固件已烧录、OpenOCD 校验通过。UART8 实测状态：双轮请求和实际输出 100‰、故障 0，左右编码器增量约 2–4 count/10 ms。编码器符号、车体行进方向及负载表现仍待验收。

用户观察到双轮正命令时左轮向后、右轮向前。左轮电气驱动方向已取反；编码器仍输出原始符号，调整后实物方向待确认。

按用户负载测试要求，调试命令占空比范围调整为 -800～800‰，单次限时仍为 10～2000 ms。上电测试仍为 100‰，持续 60 秒。

用户确认双轮向前时左编码器增量为负、右编码器为正；现对左轮增量取反并据此累计，硬件原始 counter 保留。调整后的实际正反向仍待复核。

用户确认双轮底盘电机测试无问题。完成测试后移除临时上电自动运行；此清理版本的固件待烧录。
