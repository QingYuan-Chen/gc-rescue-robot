# 转向环与识别夹取实施规划

日期：2026-11-12。适用工程：TB67H450、左轮 M2 / 右轮 M1、STM32H750 + MaixCAM Pro。

建议按“轮速与停稳验收 → 差速接口 → IMU 转向 → 视觉识别与标定 → 对准接近 → 停稳夹取”推进。第一版完成固定相机、单目标、低速接近和夹取确认；云台搜索在这条链路通过后接入。各阶段先完成自身验收，再运行依赖它的组合动作。

本次交付为实施规划。控制参数、距离阈值、时限和性能指标分别标注实测项或验收草案；固件实现与上板验证在后续阶段开展。

## 3. 控制结构与接口

```text
任务状态机：搜索 / 对准 / 接近 / 夹取
              │
              ├─ 定角转向、保向：目标航向 + IMU → ω
              └─ 视觉对准、接近：当前目标观测 → v、ω
                                      │
                                底盘差速换算
                                      │
                             左右轮目标 RPM 快照
                                      │
                   wheel_io 唯一车轮任务 → 双轮 PI → motor

任务状态机 ── 开合请求 → 夹爪模块 → PE11
```

### 3.1 差速与限速

车体前方为 `+x`，左方为 `+y`，逆时针偏航为正。线速度使用 m/s，角度使用 rad，角速度使用 rad/s，轮速使用 RPM。

```text
v_left  = v - ω × B / 2
v_right = v + ω × B / 2
rpm_left  = 60 × v_left  / (π × D_left)
rpm_right = 60 × v_right / (π × D_right)
```

两轮按各自已验收的正反向工作范围约束；超限时采用同一个缩放比例，保持请求曲率。`v`、`ω` 均限制变化率，并核对现有轮速斜坡对实际转弯的影响。最低稳定转速、可达角速度和夹取低速由落地数据确定。

自动控制接口首批只覆盖：设置 `v/ω`、相对定角转向、给定速度下保向、停车及状态查询。短距离移动作为接近终段和夹取验证的辅助动作，同样带位移上限与超时。

### 3.2 控制权与请求生命周期

- `wheel_io` 继续独占正常车轮输出。底盘和任务通过公开接口交接双轮请求，电机 PWM/GPIO 写入留在现有执行层。
- 调试保留当前“设置目标后持续运行、显式停止结束”的行为。自主动作使用独立的 `source/seq/issued_ms/valid_for_ms` 契约，车轮任务每周期检查有效期。
- 高频请求保存为单个最新快照，同时更新左右轮；停止请求具有最高优先级，并清除旧运动请求。调试参数及回执沿用事件队列。
- 增加明确的调试/自主控制权；进入自主前确认停稳。自主期间手动速度请求返回占用原因，人工停止随时有效。
- 反馈失效或动作失败向任务层返回具体原因。恢复后由任务重新检查目标和位置，再发新动作。

现有速度事件队列每周期消费一项，且结果需要读取；直接向其中持续灌入外环指令会带来排队延迟及容量限制。自主请求快照应在接入转向前完成，并验证生产者停止更新后的停车行为。

### 3.3 调度与停稳

轮速继续每 10 ms 执行。航向控制可从 20 ms 调度起步，实际输入频率按 IMU 能力确定；外环带宽依据轮速阶跃实测结果选择，起步低于内环约 3～5 倍。视觉按新帧更新目标，控制任务检查快照年龄；串口接收、推理、日志和机构等待采用非阻塞流程。

增加公共 `motion_stopped` 状态：左右轮在连续时间窗内各自满足累计绝对编码器增量门限，并满足有效速度反馈条件。显式停车后仍持续更新该判据。现有 `WHEEL_SPEED_BRAKE` 中的 100 ms / 1 count 逻辑作为待实测候选，结合轮径、负载和夹取容差确定最终值。

## 4. 转向环方案

### 4.1 先验证 IMU

1. 独立接收并验证帧完整性、校验、序号或更新时刻、量程、数据间隔；输出 `yaw_rad`、`yaw_rate_rad_s`、采样/接收时刻、有效状态。
2. 车体静止时建立本次动作的相对航向零点；记录静止漂移和转动后的恢复表现，验证安装坐标变换。
3. 人工或治具进行左/右 90°、跨 ±180° 旋转，核对角度与角速度的方向、单位和连续性。
4. 测量电机运行和夹爪动作时的干扰。对仅提供相对航向的设备，记录漂移随时间增长的范围，定期以已验证视觉对准更新任务参考。

### 4.2 第一版采用角度 P 与角速度阻尼

```text
e_yaw = atan2(sin(yaw_target - yaw), cos(yaw_target - yaw))
ω_raw = Kp_yaw × e_yaw - Kd_rate × yaw_rate
ω_cmd = 限幅并限制角加速度后的 ω_raw
```

先整定 P，再加入角速度阻尼抑制超调；积分项留待持续偏差的实测分析。这里的阻尼直接使用陀螺角速度。相对转向开始时记录一次目标航向，后续保持该目标；恰好 180° 时显式指定左右方向，避免误差符号抖动。

两种动作复用同一控制器：

| 动作 | 线速度 | 航向目标 | 结束依据 |
| --- | --- | --- | --- |
| 原地定角转向 | 0 | 开始航向 + 指定角度 | 角度误差与角速度持续进入容差，再确认停稳 |
| 前进/后退保向 | 给定且受限 | 动作开始时锁定或任务明确设置 | 指定里程/动作条件满足，随后停车 |

视觉对准时由视觉控制角速度；切回保向时以当前有效航向建立新参考。一次动作只选择一个转向目标来源。

### 4.3 调参顺序与观测

低角速度方向检查 → ±30° → ±90° → ±180° → 前进/后退保向 → 运输负载。每步观察目标航向、实际航向、角速度、`ω_cmd`、双轮目标/实际 RPM、数据年龄及限速状态。

初版验收草案：±90° 各做 10 次，最终外部测量误差 ≤3°、超调 ≤5°；采用量角治具或场地标线独立测角，并记录调节时间。对准精度最终按夹爪几何收紧：目标距离为 `d`、可分配横向误差为 `m` 时，航向误差预算约为 `atan(m/d)`，视觉测量和停车误差另占各自预算。

IMU 断流、异常跳变、序号停滞或转向超时均结束动作、撤销请求并停车，记录原始原因；停车后等待新的动作决策。

## 5. 识别、定位与通信

### 5.1 以现有四类模型为起点

| ID | 类别 | 首版处理 |
| --- | --- | --- |
| 0 | 绿色立方体 `green_cube` | 根据冻结的任务类别表决定是否允许夹取 |
| 1 | 蓝色立方体 `blue_cube` | 同上 |
| 2 | 橙色立方体 `orange_cube` | 同上 |
| 3 | 黑色三棱锥 `black_triangular_pyramid` | 核对赛题属性后设置类别行为 |

先验证现有 YOLO11n 权重在 MaixCAM 上的转换支持、输出坐标、类别顺序、端到端延迟和持续运行情况。量化/转换后使用同一组图片对照 PC 输出；若算子或资源受限，再选择设备工具链明确支持的轻量模型重新训练，并保留同一类别定义。

已有训练评估可作为模型候选依据。部署验收另采集独立场景，覆盖实际相机高度、远近、逆光、阴影、运动模糊、遮挡、相邻目标、夹爪入镜和空场。训练/验证/测试按采集场次划分，连拍同组放在同一个集合。记录每类漏检、误检、类别混淆和设备帧率；首版先提高近距离夹取视野的可靠性。

目标选择使用已批准类别、置信度、可接近范围和连续观测；锁定后通过类别、位置门限及框重叠维持同一目标。多目标交叉、关联歧义或类别突变时停车重确认，搜索阶段再重新选择。

### 5.2 首版固定相机标定

先测相机内参、畸变、安装高度/俯仰及相机相对夹爪的位置，固定采集分辨率、裁剪与缩放。建立车体前方平面到图像的对应关系，覆盖完整接近距离和左右偏差。

识别框中心用于粗方向判断；距离换算选择经人工标注验证的地面接触参考点，例如目标框底边中点，并逐类评估姿态和遮挡造成的偏差。用已知距离的目标实测标定残差。若框底点误差超过夹取容差，增加接触点定位或近距离特征提取。

标定输出为车体系目标位置 `x_forward_m/y_left_m`、有效观测区域和误差范围。夹取参考点由夹爪入口与实际捕获位置标定，使用该参考点计算接近误差。图像最下缘、部分截断或遮挡严重的目标单独标为位置无效。

首版保持相机姿态固定。云台后续采用少数已标定的搜索/夹取姿态；切换时停止视觉接近，等待机构与画面稳定，收到匹配姿态编号的新帧后再恢复判断。

### 5.3 新版通信契约

UART8 保留调试。视觉与 IMU 分别选择实际接线支持的独立接口，在接线确认后同步 `.ioc`、初始化及中断入口。

首版消息覆盖启动信息、任务选类请求及检测结果，统一帧头、协议版本、消息类型、载荷长度、序号和 CRC16；字节序、字段宽度、长度上限及 CRC 参数在实现前固化成协议文档和测试向量。

| 检测结果字段 | 用途 |
| --- | --- |
| 会话编号、帧序号 | 识别设备重启、重复帧和旧观测 |
| 采集时刻、发送时图像年龄、STM32 接收时刻 | 计算观测时效和诊断延迟 |
| 模型/类别表版本、标定版本、相机姿态编号 | 保证坐标和类别解释一致 |
| 图像宽高、目标数量 | 解释框坐标；零目标帧持续发送 |
| 每个目标的类别、置信度、框坐标、关联 ID | 候选选择、跟踪与目标关联 |
| 相机/推理状态 | 区分画面有效且无目标、设备故障和通信断流 |

两设备时钟分别计时。首版用“发送时图像年龄 + 测得的传输/缓冲上界 + STM32 接收后的经过时间”估计当前观测年龄；发送方使用最新图像并控制队列长度。标定映射放在 MaixCAM 感知侧，接近所用的米制坐标与位置有效状态随检测结果传输。

CRC 失败、版本不符、越界长度、非法坐标和旧序号应拒绝并计数；有效快照到期后撤销视觉动作。零目标、无效定位和设备异常分别报告，调用方根据明确状态处理。接收中断仅收字节，完整帧解析放入任务。

最大接近速度与数据时效共同确定。保守预留距离满足：

```text
预留距离 ≥ v ×（观测年龄上限 + 控制响应时间）
           + 实测制动距离上界 + 位置测量误差 + 机械余量
```

先测延迟、停车距离与标定误差，再确定视觉过期门限和接近速度。

## 6. 单目标识别夹取流程

```text
准备 → 搜索 → 锁定目标 → 转向对准 → 低速接近
                                  → 近距定位 → 停稳复核 → 闭合 → 夹取验证
任一阶段失败 → 撤销运动 / 保留原因 → 静止重观察或结束本次动作
```

| 状态 | 具体动作 | 正常推进条件 | 失败处理 |
| --- | --- | --- | --- |
| 准备 | 确认速度配置、IMU/视觉数据、标定及控制权；打开夹爪并等待动作时间 | 夹爪准备等待完成、车轮停稳、新帧有效 | 显示缺失项，保持等待 |
| 搜索 | 低速分段旋转，每段停稳观察；起步角度按实际视场重叠确定 | 获得允许类别的连续候选 | 总扫描角/时间到限则结束搜索 |
| 锁定 | 固定候选关联 ID，复核类别与可达位置 | 多帧稳定，关联无歧义 | 清除候选，重新观察 |
| 转向对准 | `v=0`，由视觉方位误差生成受限角速度 | 连续新帧进入对准容差 | 丢失或位置无效则停车 |
| 低速接近 | 方位误差小才前进；随距离减速，持续修正方向 | 进入近距有效标定区域 | 偏差过大先停车对准；无接近进展则超时退出 |
| 近距定位 | 使用夹爪坐标下的前后/左右误差，进一步降低速度 | 目标进入允许捕获区域，余量满足停车要求 | 接近位移超限或目标被遮挡则停车重观察 |
| 停稳复核 | 请求减速停车，读取连续停稳状态，再检查最新目标位置 | 停稳且目标仍在夹取窗口 | 目标偏移则重新对准；等待超时退出 |
| 闭合 | 调用夹爪闭合接口，保持底盘静止 | 命令采用且标定动作时间已完成 | 输出异常或等待超时则上报失败 |
| 夹取验证 | 观察目标在机构有效区域；条件允许时做已验证的小距离保持测试 | 取得事先定义的正向夹持证据 | 证据不足标为 `UNCONFIRMED`，重观察或退出 |

对准与接近可从简单 P 控制开始：`θ=atan2(y_left,x_forward)`，方向由 `θ` 或夹爪参考点对应的视觉误差生成；前进速度由剩余距离生成，并受到误差门控、停止距离和动作速度上限约束。近距阶段以已标定捕获窗口为目标，第一版采用停—转—进的分段修正，减少机构扫到相邻目标的机会。

初版要求接近终段仍有可用的目标观测。若实物出现固定盲区，先测盲区长度和最后可靠位置，再单独验收“停稳定位 → 编码器限距前进”的终段动作；动作带明确距离上限、时间上限和障碍余量，之后再纳入流程。

### 6.1 夹爪接口与成功定义

将现有按键输出提炼为单一夹爪模块，提供打开、闭合、状态查询；按键和任务都提交请求。状态至少区分 `command_applied`、`motion_wait_complete`、`grasp_confirmed`。机械动作等待采用时间戳推进，车轮任务持续运行。

保留当前 PE11、1750/2300 μs 的接入基础，实测开合耗时、夹持后保持需求及阻挡情况下的响应。TIM7 的输出所有权集中在舵机模块；后续接入 PE9 云台时统一处理两个输出的时序，保留 TIM1 的右轮资源。

夹取成功按实际机构定义：目标进入夹持/环内有效区域，闭合后在预先验证的保持测试中保持约束，并能获得视觉或已有传感器的正向证据。目标消失时转入重新观察。若机构持续遮挡且现有传感器无法提供证据，状态保持 `UNCONFIRMED`；此时需要调整观察姿态或确定额外检测手段。

首版失败策略采用停车、重观察；只有脱离路径已确认且反馈有效时才进行限距退让与重试。每次新尝试重新定位，重试次数和总时限在单目标试验中确定。

## 7. 分阶段交付与验收

| 阶段 | 最小交付 | 进入下一阶段的条件 |
| --- | --- | --- |
| P0 运动与机械基线 | 左右轮正反向 PI 实测、几何参数、最低稳定速度、停稳窗口、负载停车距离、夹爪可用范围 | 两轮和夹爪分别通过实车验收；形成可用速度范围 |
| P1 差速接口与 IMU | 底盘 `v/ω` 换算、最新请求快照、自主请求有效期、公共停稳状态、IMU 驱动与快照 | 单位/方向/限速正确；过期停车、停止优先、IMU 跨角度与失效测试通过 |
| P2 转向与保向 | 相对定角转向、前进/后退保向、调参观测 | 逐级角度测试、负载测试、独立角度测量及失效退出通过 |
| P3 视觉观测 | 四类设备推理、类别表、通信解析、固定姿态标定、目标锁定 | 独立实景评估完成；坐标误差、延迟和断流处理满足接近预算 |
| P4 对准与接近 | 搜索、锁定、视觉对准、减速接近、停稳复核 | 多个起始偏角/距离下停在夹取窗口；遮挡、错类、旧帧和超时退出通过 |
| P5 自动夹取 | 自动开合、动作等待、夹取证据、有限重试 | 指定类别的单目标流程重复通过，形成可复现记录 |
| P6 云台扩展 | 搜索/夹取姿态、对应标定、姿态切换等待 | 云台切换和夹爪并行运行时图像、脉冲、轮速与停止行为通过 |

P3 的数据采集、模型转换和协议离线测试可与 P1/P2 同期准备；P4 实车组合运行依赖 P0～P3 验收。交付、分区和整场策略在单目标夹取稳定后另行规划。

### 7.1 有价值的自动检查

- 转向：跨 ±π、恰好 180° 的方向选择、左右符号、正反速度换算、双轮共同比例限速、到位窗口被扰动后的重计时。
- 请求：高频更新保持最新值、双轮同时生效、停止优先、时效回绕、生产者停止更新、调试/自主控制权切换。
- 视觉：分包/粘包、截断/坏 CRC、长度上限、序号回绕/重启、无目标帧、标定不匹配、多目标关联歧义。
- 动作：视觉失效时撤销接近、等待停稳后才闭合、闭合等待与成功证据分别推进、超时结束、恢复后新动作重新定位。

单元测试直接调用正式计算/解析模块；硬件依赖用替身。涉及固件的各阶段按项目预设完成 Debug/Release 构建，再执行对应硬件测试。

### 7.2 实车评价草案

| 项目 | 建议测试组合 | 记录/判据 |
| --- | --- | --- |
| 转向 | 左右 30°/90°/180°，各方向重复，空载与实际运输负载 | 外部实测最终误差、超调、耗时、饱和比例；90° 先按 3°/5° 草案评估 |
| 保向 | 场地允许长度内前进、后退，并施加小初始偏角 | 航向误差、末端横向偏差、停止距离；阈值由通道宽度分配 |
| 近距定位 | 左/中/右起点 × 近/中/远距离 × 实际光照 | 停稳后的目标相对夹爪位置；横向误差预算取入口剩余间隙的一半再扣机械余量 |
| 夹取 | 每个允许类别至少 20 次，覆盖偏角、距离、朝向和相邻干扰 | 首次成功数/总数、含重试成功数/总数、耗时分布、失败原因；首次成功率 ≥90% 作为初版草案 |
| 故障 | IMU/视觉断流、冻结帧、模型/标定版本不符、动作超时、人工停止 | 记录触发到撤销输出的时间与额外位移，均满足该工作速度的距离预算 |

草案用于初版工程验收；最终目标按实际夹爪容差和场地要求调整。每次记录固件/模型/参数版本、供电、负载、地面、起始条件、成功依据及失败原因。

## 9. 当前建议先做的一个增量
