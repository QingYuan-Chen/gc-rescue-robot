# 底盘差速与转向环调试

日期：2026-11-16。底盘层在速度环之上提供差速 `v/ω`、原地定角转向和直行保向；车轮输出仍由 `wheel_io` 独占。

## 1. 几何与换算

- 轮径 65 mm，轮距 220 mm，编码器 1980 counts/输出轴转。
- 轮周长约 204.2 mm，1 count 约 0.103 mm。
- 1 rad/s 原地转向时，每轮约 32.3 RPM。
- 正向速度上限 300 mm/s（约 88.2 RPM），仍低于速度环 97 RPM 上限。

车体前方为 `+x`，逆时针（左转）为正：

```text
v_left  = v − ω·B/2
v_right = v + ω·B/2
```

差速换算采用转向优先：角速度先限到两侧轮速允许范围，再限制线速度，使两轮都在 −81～97 RPM 内。

## 2. 命令

UART8，115200 8N1，FireWater，命令以换行结尾。

```text
chassis vw <v_mm_s> <w_deg_s> <ms>       // 限时差速
chassis turn <deg>                       // 相对原地转向，±360°
chassis straight <v_mm_s> <ms> [mm]      // 锁定航向直行，可选距离
chassis stop
chassis get
turn set <param> <value>
hold set <param> <value>
hold get
motor stop
```

`turn`、`straight`、`hold` 也可作为独立命令使用。所有底盘动作都需要 IMU 有效；速度与角速度范围和时长受限。

`chassis get` 返回模式、`v/ω`、积分项 `i_mdps`、左右目标 RPM、目标/实际航向、误差、角速度、里程、剩余时间、饱和、IMU 有效、settled 和停车原因。`hold get` 返回保向环全部参数。

模式：0 空闲、1 差速 `vw`、2 定角转向、3 直行保向。停车原因：0 无、1 完成/到期、2 转向超时、3 IMU 失效、4 主动停车、5 输出被拒绝。

## 3. IMU 航向

JY61P 使用 USART3 PD8/PD9，115200 8N1。先用 `imu rate 100`（或厂家上位机）把输出频率配置为 100 Hz；10 Hz 不能满足 50 ms 失效判断。命令会保存配置，随后用 `imu get` 确认 `period_ms≈10`。

`imu get` 新增一行：

```text
OK imu heading yaw_mdeg=... rate_mdps=... age_ms=... period_ms=... valid=... jump=...
```

安装轴和符号在 `App/config/chassis_config.h`：

```c
CHASSIS_IMU_YAW_AXIS 2U
CHASSIS_IMU_YAW_SIGN 1.0f
CHASSIS_IMU_RATE_SIGN 1.0f
CHASSIS_IMU_TIMEOUT_MS 50U
```

航向由角度帧逐帧展开成连续值，跨 ±180° 不跳变；相邻帧变化超过 0.5 rad 判为跳变并暂时失效。

## 4. 转向控制

```text
e_yaw = target − yaw
ω_raw = Kp·e_yaw − Kd·yaw_rate
ω_cmd = 限幅到 ±ω_max，再限制角加速度
```

- D 项直接使用陀螺角速度，即微分先行。
- 目标航向在动作开始时锁定为“当前航向 + 角度”；180° 和 360° 不会出现方向歧义。
- 结束判据：角度误差和角速度持续进入容差 100 ms。
- 转向超时 5 s；IMU 断流、跳变或输出被拒绝时立即停车。

直行保向复用同一控制器，使用较小的增益和 ω 限幅；航向在动作开始时锁定。

## 4.1 直行保向积分

直行时两轮的实际线速度不一致（轮径差、负载差、打滑）会让车头停在固定偏角上，只有 P 时稳态误差为 `所需纠偏角速度 / Kp`。因此直行环加入弱积分：

```text
ω_raw = Kp·e + I − Kd·rate
满足条件时：I += Ki·e·dt，I 限幅到 ±I_limit
```

积分保护：

- 积分分离：`|e| > izone` 时冻结积分，不清零。
- 条件积分：输出已达到 `ω_max` 且与误差同向时，不再同向积分。
- 低速冻结：`|v_cmd| < 30 mm/s` 时不积分，覆盖起步和末端减速阶段。
- 起步冻结：直行开始后 300 ms 内不积分，避免速度环斜坡阶段的左右轮差异进入积分。
- 每次 `straight` 开始时清零。
- 积分按输出量（°/s）存储，在线修改 Ki 时输出不跳变。

转向环不使用积分（`CHASSIS_TURN_KI 0`，且 `chassis.c` 调用时关闭积分），行为与原来一致。保向 D 项保留代码，当前 `Kd=0`：实测很小的 Kd 也会引起直行振荡。

## 6. VOFA 波形

`vofa period 20`。

### 6.1 `vofa on chassis`

时间、`v` mm/s、`ω` °/s、左目标/反馈 RPM、右目标/反馈 RPM、陀螺角速度°/s、编码器角速度°/s、饱和标志。

### 6.2 `vofa on turn`

时间、目标航向°、实际航向°、误差°、陀螺角速度°/s、`ω_cmd` °/s、左/右目标 RPM、模式、停车原因、IMU 年龄 ms。

## 7. 调参顺序

1. **IMU 静态**：手转车体，确认 `imu get heading` 的 `valid=1`、`period_ms≈10`、左转/右转符号和 ±180° 连续。
2. **差速方向**：架空执行 `chassis vw 0 30 1000`，确认左轮后退、右轮前进（左转）。
3. **差速比例**：低速落地转圈，对比 `vofa on chassis` 的陀螺 ω 和编码器 ω，校正轮径/轮距。
4. **转向 P**：`turn set kp` 从小开始，做 ±30°；再加 `kd` 抑制超调。
5. **±90°/±180°**：每档多次，记录误差、超调、调节时间和 `stop_reason`。
6. **直行保向**：先 `hold set ki 0`，`chassis straight 200 3000` 直行 2 m 左右，用 `vofa on turn` 记录稳态航向误差；再取 `ki` 0.05、0.1、0.2，看误差是否收敛到 0 且没有低频左右摆动。动作结束用 `chassis get` 看 `i_mdps` 是否长期顶在 `ilimit`。
7. **失效保护**：拔掉 IMU 或断开串口，确认停车且 `stop_reason=3`。

## 8. 验收草案

- ±30°、±90°、±180° 各 10 次；外部量角，最终误差 ≤3°、超调 ≤5°。
- 直行 1000 mm，用卷尺量距并记录横向偏差；用实测结果校正轮径。
- 推扰和负载下保持方向稳定；`motor stop` 任何时候立即停车。
- IMU 数据超时、跳变、校验错误时不得继续驱动。

本版本尚未烧录、未操作硬件；方向、IMU 安装轴、轮径/轮距和参数均待上板确认。
