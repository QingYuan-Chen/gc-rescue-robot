# 基础电机与编码器接口

当前 TB67H450 底盘：左轮 M2、右轮 M1。上电保持关闭，调试命令显式驱动。

速度环及 VOFA+ 滑块调参接口见[速度环调试说明](底盘速度环VOFA调试.md)，差速、定角转向和直行保向见[差速与转向环调试](底盘差速与转向环调试.md)；位置环已撤出固件，速度环、底盘动作、JY61P 和夹爪均待上板验收。

| 功能 | 引脚 | 资源 |
| --- | --- | --- |
| 左轮 M2 IN1 / IN2 | PA5 / PB3 | TIM2 CH1 / CH2，AF1 |
| 右轮 M1 IN1 / IN2 | PA8 / PA11 | TIM1 CH1 / CH4，AF1 |
| 左轮编码器 | PA0 / PA1 | TIM5 CH1 / CH2，AF2 |
| 右轮编码器 | PA6 / PA7 | TIM3 CH1 / CH2，AF2 |
| 调试 UART8 | PE1 TX / PE0 RX | CN5，115200 8N1 |

PWM 为 20 kHz，命令占空比单位千分比，范围 ±800，时长 10～2000 ms。正向驱动对应车体前进；正常停车先同步提交双低，再切换 GPIO。致命故障关闭仍存在逐脚切换瞬态风险。

编码器 10 ms 采样，`counter_*` 为原始 16 位计数，`delta_*` 和 `total_*` 以车体前进为正。每转计数、滤波及负载表现尚待完整验收。

VOFA 选择 FireWater，默认关闭上报；发送 `vofa on left`、`vofa on right`、`vofa on both` 查看速度波形，`vofa on chassis`、`vofa on turn` 查看差速和转向波形，`vofa period 20/50/100` 设置上报周期。文本命令以换行结尾：`motor both 100 100 2000`、`motor left 100 1000`、`motor right 100 1000`、`motor stop`、`motor status`、`chassis vw 100 0 1000`、`chassis turn 90`、`chassis straight 100 2000`、`chassis stop`、`chassis get`。单轮命令将另一轮置零。详见 [联调记录](validation/2026-11-10-m1-m2-uart8.md) 和 [差速与转向环调试](底盘差速与转向环调试.md)。

`rescue.ioc` 与当前分配同步；完整 CubeMX 重生成尚未验证，`Core/Src/tim.c` 手写初始化有覆盖风险。调试参数为实验值，实际电流与负载需现场测量。
