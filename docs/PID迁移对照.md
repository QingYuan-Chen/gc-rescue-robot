## 计算与状态更新

两种 PID 都按调用次数离散计算，不额外乘除采样时间。每个控制器使用独立状态；`target` 和 `measurement` 每步写入，误差为 `e = target - measurement`。

增量式保留以下顺序：

1. 比例增量为 `e - previous_error`。
2. 以上一步内部累计输出判断积分：严格大于 `output_max` 时只允许负误差参与；严格小于 `-output_max` 时只允许正误差参与；其余情况采用本次误差。恰好等于边界时仍允许积分。
3. 差分为 `e - 2 * previous_error + previous2_error`。
4. 累计 `output += kp * proportion + ki * integral + kd * differential`，再推进两级误差历史。

`output_max` 是积分抑制阈值，算法内部输出并不被截断。实际驱动限幅不能回写到该状态，否则下一步的积分判定会改变。增量式不使用 `output_min` 和微分滤波参数。

位置式保留条件积分、滤波及限幅：上一步输出 `>= output_max` 时只累加负误差，`<= output_min` 时只累加正误差，其余情况直接累加；`differential = (e - previous_error) * filter + (1 - filter) * previous_differential`；计算 `kp * e + ki * integral + kd * differential` 后夹在上下限内，再更新误差和滤波历史。此处的边界比较与增量式不同，不能合并成同一饱和判断。

`pid_incremental_reset()` 对应原 `motor_pid_clear()` 的全状态清零，但一次只清一个实例。`pid_positional_reset()` 提供与原位置式全零启动状态相同的显式复位；原 `pid_init()` 不清位置式历史，本次没有增加任何隐式复位调用。

原 `MOTOR_STOP` 只写零电机输出，不自动清 PID。零目标也不等于停车：全零初态下，目标 1、反馈 0 时原内部输出为 1780；下一步目标、反馈均为 0，内部输出仍为 180。新算法保留该结果。阶段 4 按 [底盘控制规则与比赛动作](底盘控制规则与比赛动作.md) 接入：零速度仍保持闭环和历史状态，显式停车才归零电机输出、撤销请求并清 PID；进入/退出控制的清零时机属于新控制层行为，单独验收停止及重启，不改 PID 公式来实现停车。

## 周期、反馈与方向

原 `motor_task()` 声明 10 ms 周期，反馈由编码器本周期计数提供。新 `wheel_pid_step_duty_permille()` 要求每 10 ms 调用一次，目标为浮点 counts/10 ms，反馈为有符号整数 counts/10 ms；不是累计计数、counts/s、RPM 或 m/s。周期通过编译期断言与 `WHEEL_PERIOD_MS` 绑定，改周期不能继续无说明地使用这组参数。

旧反馈每次读取后清零计数器，新驱动采用连续计数器差分和回绕处理。周期增量由阶段 2 验收保证，新 PID 直接使用该公开反馈，不再次清硬件计数器。

当前 C 左轮对应 TIM4，D 右轮对应 TIM8；电机正命令已由用户确认是前进，编码器符号分别为 +1、-1。旧 `get_encoder()` 对 TIM4/TIM8 都取负，不能再把这两个旧负号叠加到已校准的新反馈上。新算法统一使用“前进为正”的目标和反馈，输出符号交给现有电机驱动处理。

## 输出单位换算

原 PID 输出是 TIM1 CCR 计数，原配置 `ARR=1999`，完整 PWM 周期为 2000；原上限是 `(int32_t)(1999 * 0.8f)=1599`。保留这个基准才能使原 Kp、Ki、Kd 的输出含义不变。

原任务先将 PID 输出向零截断为 `int32_t`，驱动再夹到 ±1599。新适配先将有限浮点输出夹到 ±1599，再向零截断；在原转换有定义的范围内，两者得到相同整数。随后执行：

```text
有符号占空比千分比 = 有符号 CCR 整数 × 1000 / 2000
```

这里使用整数除法向零截断，不改变 PID 内部浮点输出。

| 原 PID 输出 | 原驱动最终有符号 CCR | 原占空比千分比 | 新驱动请求千分比 |
| ---: | ---: | ---: | ---: |
| 0.9 | 0 | 0 | 0 |
| 1.9 | 1 | 0.5 | 0 |
| 500.9 | 500 | 250 | 250 |
| 1599 | 1599 | 799.5 | 799 |
| 3000 | 1599 | 799.5 | 799 |
| -1599 | -1599 | -799.5 | -799 |

当前 TIM12 `ARR=999`，周期 1000，与千分比接口逐计数对应；相对原整数 CCR 的占空比，新增向零量化差为 0 或 0.5 千分比，即最多 0.05 个百分点。不能将原数值 1599 直接当成千分比，也不能把上限四舍五入写成 800。

原 TIM1 配置为 50 Hz，当前车轮 TIM12 为 1 kHz；继续保持阶段 2 的 TIM12 配置。这里验证的是算法和占空比数值映射，PWM 频率改变后的机械响应不保证相同，需在速度闭环阶段实测。±799 千分比是原参数适配上限，UART 手动开环限制仍为 ±300 千分比。阶段 4 新增限时速度命令，并在适配之后将首次闭环验收输出限制为 ±250 千分比；该限制及换向零输出不回写 PID 内部状态，也不修改原算法参数。

首次上板给定 3 counts/10 ms、持续 500 ms，观测反馈 -4～+5。按原 Kp，反馈变化 1 个计数时比例项变化 1600 CCR，即 800‰；首帧误差 3 得 5340 CCR，与实测一致，暂未发现公式或单位换算错误。提高目标到 8、10 后，1.5 秒测试窗口均速分别为 7.08、9.73 counts/10 ms；10 档的活动快照反馈为 9～10，但实际输出均达到 +250‰ 上限。目标工作点影响明显，低速跟随问题不能推广到所有速度；负输出可以是减速纠偏，不能单独作为异常判据。原参数继续保留，增益、实际限幅与换向间隔各自贡献仍待进一步验证。
