# 车轮相对位置环调试

位置命令以接收生效时的编码器累计计数为起点，左右轮独立控制，前进为正。位置环每 20 ms 更新，使用原始累计计数；P 系数初值为 0.15 RPM/count，目标速度限幅 ±20 RPM，到位容差 ±12 counts。初值位于 `App/config/wheel_config.h`，可通过 VOFA+ 调整，属于待上板整定的参数。速度环每 10 ms 执行，测速约 50 ms 更新、低通时间常数 80 ms。

## VOFA+ 滑块和波形

UART8 连接 VOFA+，选择 FireWater。使用未绑定命令的 Slider 时，将控件名称设为下表的名称，发送格式为名称加冒号和数值，命令以换行结束：

| 控件 | Slider 名称 | 实际发送示例 | 建议范围和步长 |
| --- | --- | --- | --- |
| 左轮相对位置 | `pos target let` | `pos target let:198` | −1980～1980 counts，步长 1 |
| 位置 Kp | `pos set kp` | `pos set kp:0.15` | 0.001～2 RPM/count，步长 0.01 |
| 位置 Ki | `pos set ki` | `pos set ki:0.01` | 0～2 RPM/(count·s)，步长 0.01 |
| 位置 Kd | `pos set kd` | `pos set kd:0.01` | 0～2 RPM·s/count，步长 0.01 |
| 位置速度上限 | `pos set limit` | `pos set limit:20` | 1～20 RPM，步长 1 |
| 位置容差 | `pos set tolerance` | `pos set tolerance:12` | 1～100 counts，步长 1 |

例如 `pos target let:198.000000` 直接启动左轮位置动作，固件也接受 `pos target left:198`。位置和容差要求整数值；右轮目标固定为零。动作进行中拖动滑块会更新相对本次起点的位置目标，换向先停稳。动作结束后再次拖动滑块会以新的编码器位置为起点；空闲时发送零保持空闲，动作中发送零会将目标设回本次起点。收到 `OK pos target_left=... id=...` 表示已接收；波形随后显示控制周期生效的目标。

位置参数对左右轮共同生效，只在车轮空闲时接受；收到 `OK pos config` 后已生效。参数保存在 RAM，复位恢复固件初值：Kp 0.15，Ki 和 Kd 均为 0。滑块也支持 `pos set ki:0.01` 和 `pos set kd:0.01`。`pos get` 中 `kp_millionths`、`ki_millionths`、`kd_millionths` 为对应参数的百万倍，`limit_mrpm` 为上限 RPM 的千倍，`tolerance` 为 counts。微分项采用编码器位移变化率；积分限幅并在停车及补偿起步时清零。

发送 `vofa on pos` 开启位置波形，`vofa period 20`、`50` 或 `100` 设置上报周期，`vofa off` 关闭。8 个通道依次为：时间 ms；左轮目标、实际和误差 counts，左轮位置环目标 RPM、测量 RPM、实际 PWM ‰；位置状态码。状态码依次为 0 空闲、1 排队、2 运行、3 到位、4 主动停车、5 超时、6 补偿后超差、7 故障。位置波形与原速度波形共享上报通道，`vofa on left/right/both` 切回速度视图。

## 基本命令

通过 UART8（115200 8N1）发送：

```text
speed set left limit 250
speed set right limit 250
pos move 198 0
pos get
motor stop
```

`pos move <left> <right>` 的两个参数为整数 counts，各为 −1980～1980；零表示该轮不参与。两轮同时为零或控制权被占用时返回 `ERR`。收到 `OK pos queued id=...` 后用 `pos get` 查询，返回同一动作编号。动作执行期间，开环、速度目标、新位置动作和速度参数生效命令会被拒绝；停车命令优先。

`pos get` 包含状态 `idle`、`queued`、`running`、`done`、`stopped`、`timeout`、`overshoot` 或 `fault`；`target`、`actual`、`error` 为左右轮 counts，`target_mrpm` 为左右轮目标 RPM 的千分之一，`elapsed_ms` 为生效后的时间，`corrections` 为每轮补偿次数。终态保留到下一条位置命令。到位后走速度环减速和停稳，最终偏差超出容差时每轮最多补偿一次；10 秒超时或补偿后超差会关闭输出并记录原因。

先架空、单轮、限幅 250‰，将目标设为 +198 和 −198 counts，各执行三次，再检查双轮不同位移。每次记录最终误差、耗时、过冲、补偿次数与停车状态。只有达到最终误差 ±12 counts 且输出关闭，才算该次到位。初始参数、低速跟随、方向、制动及实车停车仍需验证；实车轮径和编码器每圈计数需独立校准。
